# Hi-POS
Software de punto de venta para negocios de comida.

## Versión 1.0.0
¿Que incluye?
Lista de funcionalidades:
- Personalización del negocio
- Modo demo y modo full mediante licencia
- Datos de prueba dedicados a diferentes giros (pizzería, cafeteria, bar)
- Gestión de ordenes por mesas
- Gestión de ordenes por envíos a domicilio
- Gestión de ordenes para llevar
- Reportes de ventas diarias y estadisticas básicas de ventas
- Gestion de inventario, platillos e insumos
- Gestión de usuarios
- Respaldos y exportación de datos para mantenimiento
- Gestión de cantidad de mesas
- Creación de descuentos y promociones
